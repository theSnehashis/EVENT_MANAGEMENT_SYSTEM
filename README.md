# Event Management System

A web-based Event Management System developed using **PHP and MySQL** as a mini project for the BCA 5th Semester.

The system is designed to manage events, user registrations, event schedules, and participant information in an organized manner.

## 📌 Project Overview

The Event Management System provides a simple platform where users can:

- View available events
- View event details
- Register for events
- View event schedules
- Check participant lists

The project is developed as part of the **PHP & MySQL Mini Project** assignment.

## 🎯 Objectives

- To develop a web-based event management system using PHP and MySQL.
- To provide an organized way to manage events and participants.
- To allow users to register for available events.
- To display event schedules and participant information.
- To apply PHP and MySQL concepts in a practical project.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Code Editor:** Visual Studio Code
